Shafra Discord Template
========================
هذا قالب بوت Discord ينشئ هيكل سيرفر عصابة FiveM باسم Shafra.

الرتب:
1. 👑 Boss
2. 🥷 Co-Boss
3. 💎 رتبة عليا
4. 🔫 عضو
5. 🟢 متدرب
6. 🤖 Bot

الأقسام والقنوات معرفة داخل bot.js.

طريقة التشغيل:
1) ثبّت Node.js 18 أو أحدث.
2) أنشئ Bot من Discord Developer Portal.
3) فعّل Server Members Intent من إعدادات البوت.
4) انسخ BOT_TOKEN إلى ملف .env.
5) شغّل:
   npm install
   npm start

تنبيه: البوت ينشئ القنوات والرتب في السيرفر الذي تضيفه إليه. لا يحتاج إلى حذف سيرفرك.
